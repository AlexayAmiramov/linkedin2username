פרטיות

  • תמונה לסקיצה והדמיה על הגוף עובדות בלי אינטרנט. שום תמונה לא יוצאת מהטלפון.

  • הגלריה נשמרת רק בדפדפן של הטלפון הזה.

מחיקת נתונים

מדריך לסטודיו

התקנה במסך הבית של האייפון

  1. פותחים את הקישור ב-Safari.
  2. לוחצים על כפתור השיתוף (ריבוע עם חץ למעלה).
  3. בוחרים "הוספה למסך הבית" ולוחצים "הוסף".

האפליקציה נפתחת מהאייקון במסך מלא. תמונה לסקיצה, הדמיה וגלריה עובדות גם בלי אינטרנט.

איך מקבלים מפתח Gemini

  1. נכנסים ל-aistudio.google.com/apikey עם חשבון Google.
  2. לוחצים "Create API key", ואם מבקשים, בוחרים פרויקט.
  3. מעתיקים את המפתח (מתחיל ב-AIza).
  4. כאן באפליקציה: הגדרות ← מדביקים ← "בדיקת מפתח".

מנוי Gemini Pro לא כולל את ה-API, אלה שני דברים נפרדים. המפתח עצמו בחינם. מודל מהיר ומודל איכותי מוסברים בהמשך.

מהיר או איכותי

  • gemini-2.5-flash-image: מהיר, וכולל כמות קטנה של תמונות בחינם ביום.
  • gemini-3-pro-image-preview: איכות גבוהה יותר. אין לו מסלול חינמי, ולכן צריך להפעיל Billing ב-AI Studio. עולה בערך כמה סנטים לתמונה.
  • אם מופיעה ההודעה "נגמרה המכסה", מחכים קצת או מפעילים Billing.

שמירה על המפתח

  • לא שולחים את המפתח לאף אחד ולא מצלמים אותו.
  • מומלץ להגביל אותו ב-Google Cloud Console: בוחרים את המפתח ← API restrictions ← רק "Generative Language API".
  • אם המפתח דלף, מוחקים אותו ב-AI Studio ויוצרים חדש.
  • בטלפון משותף, מבטלים את "לזכור את המפתח במכשיר הזה".

טיפים לסקיצה טובה

  • תמונה מוארת היטב על רקע פשוט נותנת את הקווים הכי נקיים.
  • קו נקי לתמונות מורכבות, סטנסיל להדפסה על נייר טרנספר.
  • יש נקודות קטנות מיותרות? מעלים את "ניקוי רעשים". הקווים חלשים? מעלים את "עוצמת קו".
  • לנייר טרנספר מסמנים "היפוך מראה" לפני השמירה.
  • "רקע שקוף" שומר PNG שאפשר לפתוח ב-Procreate מעל שכבות אחרות.
  • כדי לקבל סקיצה של AI מתמונה: "שיפור עם AI" במסך התמונה, ואז "יצירת סקיצה".
  • התוצאות של הרעיון מופיעות מתחת לכפתור "יצירת סקיצה". מתחת לכל תוצאה יש כפתורים: שמירה, הדמיה, עריכה ושיתוף.
  • "עריכה" פותחת את הסקיצה במסך התמונה בסגנון דיו. שם אפשר לנקות, לעבות, להפוך לסטנסיל ולהפוך מראה.

פרטיות

  • תמונה לסקיצה והדמיה על הגוף מעובדות בטלפון ולא נשלחות לשום מקום.
  • ל-Google נשלחים רק הטקסט ותמונת ההשראה, ורק כשלוחצים על "יצירת סקיצה". נתוני GPS נמחקים לפני השליחה.
  • הגלריה והמפתח נשמרים רק בטלפון הזה. בהגדרות יש כפתור שמוחק הכול.
